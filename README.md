# Banking Sector Performance Dashboard (Power BI)

## Project Overview

The Banking Sector Performance Dashboard is an interactive Power BI project designed to analyze key banking performance indicators through dynamic visualizations and dashboards. The project provides insights into customer demographics, loan distribution, deposits, account balances, and overall banking performance, enabling data-driven decision-making.

## Objectives

- Analyze key performance indicators (KPIs) of the banking sector.
- Monitor customer, loan, and deposit performance.
- Identify trends and patterns using interactive dashboards.
- Compare banking performance across different customer segments.
- Support business decision-making through visual analytics.

## Tools & Technologies
